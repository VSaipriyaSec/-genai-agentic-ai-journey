# Day 1 — AI, ML, Deep Learning, GenAI, LLM

**Study status:** Completed  
**Study duration:** Approximately 2–3 hours  

## Learning objectives

- Understand AI, ML, Deep Learning, Generative AI, and LLMs.
- Learn how these concepts are connected.
- Understand the difference between ChatGPT and Google Search.

## 1. What is Artificial Intelligence?

Artificial Intelligence, or AI, is the field of making machines perform tasks that normally require human intelligence.

Examples:

- Voice assistants
- Self-driving cars
- Face recognition
- Recommendation systems
- Chatbots

## 2. What is Machine Learning?

Machine Learning, or ML, is a part of AI where computers learn patterns from data to make predictions or decisions.

Example:

A spam filter learns from many emails labelled as spam and not spam. It then predicts whether a new email is spam.

## 3. What is Deep Learning?

Deep Learning, or DL, is a type of Machine Learning that uses neural networks with many layers to learn complex patterns from large amounts of data.

Examples:

- Face recognition
- Speech recognition
- Image classification
- Language translation

## 4. What is Generative AI?

Generative AI, or GenAI, creates new content such as text, images, audio, video, and code by learning patterns from training data.

Examples:

- ChatGPT generates text.
- DALL·E generates images.
- GitHub Copilot generates code.
- Voice-generation tools generate speech.

## 5. What is a Large Language Model?

A Large Language Model, or LLM, is a type of Generative AI that understands and generates human language.

LLMs can:

- Answer questions
- Explain topics
- Summarize documents
- Translate languages
- Write emails
- Generate code
- Extract information from text

Examples:

- GPT
- Gemini
- Claude
- Llama

## 7. Comparison table

| Term | Meaning | Example |
|---|---|---|
| AI | Machines performing intelligent tasks | Voice assistant |
| ML | Learning patterns from data | Spam filter |
| DL | Using neural networks for complex patterns | Face recognition |
| GenAI | Creating new content | ChatGPT |
| LLM | Understanding and generating language | GPT, Gemini |

## 8. ChatGPT vs Google Search

| Feature | Google Search | ChatGPT / LLM |
|---|---|---|
| Main job | Finds relevant web pages and information | Generates a conversational response |
| Output | Links, web pages, snippets | Explanations, summaries, code, text, and drafts |
| Best use | Finding current information and original sources | Writing, explaining, summarizing, brainstorming, and coding |
| Main limitation | May show too many or irrelevant results | Can generate incorrect information |

Google Search finds existing pages on the web. ChatGPT generates new responses using patterns it learned during training and the instructions in the user’s prompt.

## 9. What I learned today

- AI is the broad field of building intelligent machines.
- Machine Learning learns useful patterns from data.
- Deep Learning uses neural networks to solve complex tasks.
- Generative AI creates new content.
- LLMs understand and generate human language.
- ChatGPT is not only a search engine; it can generate explanations, code, emails, and other content.

## 10. Self-test answers

### What is the relationship between AI, ML, DL, GenAI, and LLM?

AI is the broad field of making machines perform intelligent tasks. ML is a part of AI that learns from data. Deep Learning is a type of ML that uses neural networks. Generative AI creates new content. LLMs are Generative AI models focused on understanding and generating language.

### What is the main idea behind Machine Learning?

Machine Learning learns patterns from data and uses those patterns to make predictions or decisions on new data.

### What makes Deep Learning special?

Deep Learning uses multi-layer neural networks, which can learn complex patterns from large amounts of data.

### What is new about Generative AI compared with older AI?

Traditional AI often predicts, classifies, detects, or recommends. Generative AI can create new text, images, audio, video, and code.

### What is an LLM used for?

An LLM is used to understand and generate language. It can answer questions, write emails, summarize text, translate languages, generate code, classify text, and extract information.
